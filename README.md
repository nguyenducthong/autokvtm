# Auto KVTM - Hệ Thống Quản Lý & Tự Động Hóa Nông Trại

Hệ thống hỗ trợ tự động hóa trò chơi **Khu Vườn Trên Mây (KVTM)** trên giả lập Android (LDPlayer).

---

## 📥 Tải Về Phiên Bản Mới Nhất

👉 **Truy cập mục [Releases](https://github.com/nguyenducthong/autokvtm/releases) để tải phiên bản mới nhất.**

### Hướng Dẫn Cài Đặt & Sử Dụng:
1. Tải file nén **`autokvtm_pro.zip`** từ bản phát hành mới nhất trong mục Releases.
2. Giải nén vào một thư mục trên máy tính (ví dụ: `D:\AutoKVTM`).
3. Mở thư mục và nhấp đúp vào file **`autokvtm_pro.exe`** để chạy.
4. Chọn giả lập LDPlayer đang mở và nhấn **"Chạy"** để bắt đầu.

---

## ✨ Tính Năng Nổi Bật:
- 🚀 **Khởi động siêu tốc**: Đóng gói dạng thư mục, chạy ngay trong 1-2 giây.
- 🌾 **Tự động trồng cây & thu hoạch**: Quản lý nhiều tầng mây, nhận diện chính xác từng loại hạt giống và quả chín.
- 🏭 **Tự động sản xuất**: Quản lý hàng loạt máy sản xuất theo từng tầng.
- 🏪 **Bán đồ & Gian hàng**: Tự động dọn kho, định giá và đăng bán đồ lên quầy hàng.
- 🤖 **Tích hợp Trí tuệ Nhân tạo (AI)**: Hỗ trợ tự phục hồi màn hình khi game gặp sự cố và nhận diện kho thành phẩm thông minh.
- 🔄 **Tự động cập nhật**: Tự động nhận diện bản cập nhật mới, giữ nguyên 100% file cấu hình của người dùng.
