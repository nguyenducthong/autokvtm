Phiên bản v1.0.24 - Nâng cấp Kiến trúc Đóng gói Thư mục & Hệ thống Cập nhật An toàn

1. Đóng gói Kiến trúc Thư mục (Directory Mode):
- Khởi động tức thì (1-2 giây), không còn độ trễ xả nén 150MB vào %TEMP% như bản cũ.
- Toàn bộ ảnh (assets/) và cấu hình (configs/) nằm trực tiếp cạnh file .exe, dễ dàng tùy biến mà không cần đóng gói lại.

2. Hệ thống Tự động Cập nhật An toàn 3 Lớp (Safe Auto-Updater):
- Tự động sao lưu thư mục configs/ sang backup_configs/ trước khi cập nhật.
- Bảo vệ tuyệt đối cấu hình người dùng: không bao giờ ghi đè lên các file configs/*.json, selected_device.json và ảnh tùy biến đã có.
- Hỗ trợ tải và cài đặt gói .zip mới lẫn file .exe cũ.

3. Tối ưu hóa Kết nối Giả lập & Tránh Treo Khởi động:
- Tự động dò tìm cài đặt LDPlayer qua Registry và quét mọi ổ đĩa (C-I).
- Loại bỏ hoàn toàn các popup modal gây treo ở màn hình Splash.
- Chuyển cài đặt thư mục LDPlayer vào tab "Cấu hình chung" tiện lợi.

4. Quản lý Phiên bản & Hạ cấp:
- Hỗ trợ chọn cài đặt hoặc hạ cấp về các phiên bản cũ trong lịch sử GitHub Releases.
- Tắt popup tự động cập nhật khi khởi động để người dùng chủ động hơn.
